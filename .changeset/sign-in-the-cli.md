# Sign the CLI in without copying a token

Run `npx -y @slopperday/cli login` and it opens Slopper on a one-time code. Check it matches your terminal and approve it, and the CLI gets a token of its own, which you can revoke in Settings like any other. It works from a remote machine too: open the link it prints anywhere you're signed in.
