# New API tokens stay hidden until you reveal them

A new token used to appear in full on Settings → API & MCP, and in the setup snippets below it, the moment you made it. It's now hidden behind dots, so it's safe to make one while sharing your screen or streaming. Copy it with the copy button, or press the eye to see it; the snippets show it only once it's revealed and always copy the real token.
