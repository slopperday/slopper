# Tag people and write words for some networks in one Studio post

The Studio's post field is now a live editor. Type @ to tag someone from your people (Studio settings → People): each network gets their handle there, or their name where they have none, so one post can tag @ada.bsky.social on Bluesky and @ada_builds on Instagram. Select words and pick "Only on…" to keep them for some networks, such as "Link in bio" for Instagram, or add new words for just those networks. The previews show what each network gets.
