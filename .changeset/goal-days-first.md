# Set a goal in one screen: days first, then how hard you'll go

Setting a goal now starts with how many days you're in for (7, 14, 30, 100 or your own number), then offers four paces for those days: Safe, Getting there, Hardcore and Impossible, from one slop every five days to two a day. The goal is spelled out on flip tiles as you choose, and you can still type an exact number, name it or start another day. New accounts start here, and once the goal is set you're asked to share it, because saying it out loud makes you more likely to see it through.
