# Updates with more to show

Updates can carry more than text now. Tag the version that shipped, add up to four images and three links, name the feature you shipped, or say how a field test went (worked, mixed or broke) and who tried it.

A link can show a preview card with the page's title, description and image. Cards are off until you ask for one, and you can remove one from a posted update at any time; the link stays.
