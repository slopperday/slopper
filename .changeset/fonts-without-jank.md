# Pages open without the text jumping

Headings and text used to show up in a stand-in font, then jump to Slopper's own fonts a moment later and push the page around. The fonts now come from slopper.day itself and start loading with the page, so they're usually there before anything shows; on a slow connection the stand-in is sized to match, so the page stays put when they arrive.
